# 展示案例：单图五轮共创

该案例用于豆包实际安装后的前向测试，不是产品说明书。实际输出与期望真值分开记录。

## 用户起始请求

“我上传一张我家宠物的照片，帮我做成能在 Windows 桌面上活动的桌宠。保留它的花纹，其他你帮我定。”

## 期望五轮

1. 需求：识别单图输入，默认适度卡通化、Windows x64；说明提醒/面板/文件口袋/贴边默认开，打字响应默认关；生成 spec 草案。
2. 母版：用 `image_edit` 标准化上传图，只展示一个 `core-ip`，请用户确认身份特征。
3. 动作：只引用确认后的母版，用 `image_edit` 衍生 12 状态；确定性抠图后展示联系表。
4. 功能：脚手架生成、自动测试和资产 QA；只询问是否明确授权打字响应等高影响选择。
5. 交付：Windows 真实构建、真人清单、产物 SHA-256、未签名提示；Mac 未跑则写待确认。

## 一票否决

- 在母版确认前生成完整动作或开始大规模编码；
- 每个动作独立 `image_gen`；
- 声称模型直接输出透明图，不执行 alpha 检查；
- 使用 `computer-use` 做 GUI 验收；
- 未运行构建/测试却写已完成。
