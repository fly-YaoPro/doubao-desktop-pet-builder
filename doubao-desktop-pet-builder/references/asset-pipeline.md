# 资产流水线

## 先建功能清单，再生成素材

`core-ip` 是角色身份的唯一视觉真值。先锁定轮廓、主色、五官、比例、标志配饰、材质和禁改项，再为 `pet-spec.json` 中已启用的触发器生成素材。

每个状态必须同时具备：

- `triggers`：谁会触发；
- `frames`：实际播放帧；
- 入口或系统事件：右键互动、点击、提醒、贴边、文件拖入等；
- 自动或人工验收步骤。

没有触发器的状态不要生成。条件功能关闭时，不生成其专属状态：全局打字关闭则不生成 `typing`；自动行走关闭则不生成左右行走；文件口袋关闭则不生成拖入成功/失败素材。

## 唯一母版规则

- 单图输入：用 `image_edit` 标准化上传图为 `core-ip`。
- 文字输入：只在创建 `core-ip` 时使用一次 `image_gen`。
- 所有动作：继续引用确认的 `core-ip`，提示词写明只改变动作/表情，不改变身份特征。
- 完整动作包：优先确定性修复，只有缺失或不合格的功能帧才补图。

默认向模型请求“独立透明 PNG 素材，无背景、无地面、无投影”。模型若生成常见的浅灰/白色仿透明网格，可接受为原始输入；模板会从画布边缘识别 1–3 个背景色簇并做连通泛洪。真实 alpha 透明图直接保留。不要再要求模型复现精确 HEX，因为实测模型会把它画成渐变场景，再诱导执行者改配置和放宽阈值迁就错误结果。

`assetPipeline.generationBackground` 默认写 `transparent-grid`。只有导入已有素材且仿透明网格与主体浅色冲突时，才改为 `solid-chroma`；这仍要求单一平面色、无渐变和投影，但颜色由边缘聚类识别，不把“生成出来的实际颜色”回写成配置真值。背景需要超过 92% 的边框采样由最多 3 个稳定色簇解释，否则直接返工。

模型输出必须满足：角色悬空呈现为独立贴纸/PNG 素材；无环境光、地面、底座、投影、接触阴影、色块和装饰边框。不得依据模型口述认定透明，也不得因为脚本能抠掉大部分就忽略联系表中的残留底色。

## 动作提示词骨架

每组多帧动作一次规划，逐帧继续引用同一母版：

> 保持核心角色的脸型、五官、毛色/材质、身体比例和标志配饰完全一致。为【触发入口】制作【动作名称】的第 N/M 帧：描述当前关键姿势及与前后帧的变化。角色身体基准高度、头部中心、镜头、画幅和脚底基线与本状态第 1 帧一致，四周留安全边距。输出独立透明 PNG 素材；若无法真实透明，使用浅灰/白仿透明网格。禁止场景、渐变、光晕、地面、底座、投影和接触阴影。只改变完成该动作所需的局部姿态和表情。

先列关键姿势：准备 → 接触/发力 → 反馈 → 回位。不要把多帧理解成重复生成几张近似静态图。

## 帧数基线

| 用途 | 默认帧数 | 说明 |
|---|---:|---|
| `idle` | 4–6 | 配合轻微呼吸，包含耳、尾或表情的细微变化 |
| `blink` | 5 | 睁眼 → 半闭 → 闭眼 → 半开 → 睁眼 |
| 点击/开心 | 5 | 准备 → 压缩 → 反馈 → 回弹 → 回位 |
| 首版角色互动 | 5–6 | 必须出现准备、接触、主动作、反馈、回位 |
| `notify` / `peek` | 5 | 出现、强调与回位清楚 |
| 文件拖入反馈 | 5 | 仅功能开启时生成 |
| 行走/跑动 | 6–8 | 仅自动移动开启时生成，不能用静态图平移代替 |
| 睡眠 | 4–6 | 呼吸、耳尾或气泡变化 |

新生成首版不再以 3 帧作为合格默认。交互帧间隔通常为 80–140ms，眨眼为 55–90ms；需要停顿时在状态机中延长关键帧或重复节奏，不把每帧拖到 200ms 以上制造卡顿。

## 确定性处理

1. 优先接受真实 alpha；否则从整圈画布边缘识别背景色簇。`transparent-grid` 只接受低饱和浅色网格，`solid-chroma` 只接受稳定平面色。边缘色簇超过 3 个、覆盖不足 92% 或呈明显渐变时失败。
2. 只删除与识别色簇接近且从边缘连通的背景；不做全图“近白即透明”，避免误删角色白毛和眼白。
3. 主体触边、背景与主体冲突、残留色块、地面/投影、宽而扁的底部连通块或前景误删时失败返工。禁止回写背景色、放宽阈值或增加羽化来掩盖原图不合格。
4. 去色边，检查真实 alpha、透明像素比例和非主体连通块。
5. 同一状态先完成全部抠图，再使用同一个缩放系数归一化到 512×512；禁止每帧各自“尽量放满画布”。保持底部中心锚点，主体最大边默认占画布 72%–80%。
6. `idle`/`blink` 的宽高漂移不得超过 2.5%，中心漂移不得超过 1.5%；其他动作默认不得超过 8%，超出时返工而非用独立缩放强行对齐。
7. 生成资产报告、素材链接报告、体验覆盖报告、联系表和对齐图。联系表按状态分组，标注触发入口、帧序号、尺寸和锚点漂移。
8. 从处理后的 `core-ip` 生成 32×32 透明托盘 PNG，检查非空、主体占比和边缘清晰度。

禁止旋转整张身体伪造局部动作，也禁止用同一张图片重复命名来伪造多帧。

## 扩展动作词表

按真实互动增补：`pet`、`eat`、`play`、`sleep`、`stretch`、`lick`、`tail-wag`、`fetch`、`hop`、`charge`、`wave` 等。词表只是灵感，不强制数量。
